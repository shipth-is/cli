# Command: `game archive`

## Description

Archives a game. An archived game is not shown in your game list, and you cannot ship it.

## Help Output

```help
USAGE
  $ shipthis game archive [-g <value>]

FLAGS
  -g, --gameId=<value>  The ID of the game

DESCRIPTION
  Archives a game. An archived game is not shown in your game list, and you cannot ship it.

EXAMPLES
  $ shipthis game archive

  $ shipthis game archive --gameId 0c179fc4
```
