# Command: `game unarchive`

## Description

Unarchives a game. The game is shown in your game list again, and you can ship it.

## Help Output

```help
USAGE
  $ shipthis game unarchive [-g <value>]

FLAGS
  -g, --gameId=<value>  The ID of the game

DESCRIPTION
  Unarchives a game. The game is shown in your game list again, and you can ship it.

EXAMPLES
  $ shipthis game unarchive

  $ shipthis game unarchive --gameId 0c179fc4
```
